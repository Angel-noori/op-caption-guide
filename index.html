{release_group}ExtraFlix.Pw / MeGusta
Smart optional cleanup

{lang_display} shows one language normally, multiple languages inside brackets, and nothing when unavailable. Existing [{languages}] templates get the same smart behavior automatically. Empty optional groups such as ({year}), [{ott}] or [Subs: {shortsub}] disappear cleanly instead of leaving empty punctuation.

Compatibility note

{quality} stays compatible with older OP captions and normally means resolution. Use {source_quality} when you specifically want WEB-DL, BluRay, REMUX, etc.
